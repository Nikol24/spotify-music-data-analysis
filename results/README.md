
# Spotify Analysis Results

This directory contains the generated outputs
of the Spotify Music Data Analysis project.

## Visualizations
- Genre distribution
- Popularity distribution
- Average popularity by genre
- Energy vs popularity
- Danceability vs popularity
- Audio feature correlation matrix
- PCA clustering visualization

## Statistical Results
- Top 10 genres
- Average popularity by genre
- Correlation matrix
- Cluster summaries
- Silhouette scores

All outputs are generated using the Python
scripts in the src directory.
