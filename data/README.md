
# Spotify Dataset

Source: Kaggle - Spotify Tracks Dataset by Maharshi Pandya.

Dataset URL:
https://www.kaggle.com/datasets/maharshipandya/-spotify-tracks-dataset

Original file: dataset.csv

The dataset contains approximately 114,000 Spotify track records,
including track metadata, popularity scores, audio characteristics
and music genres.

The original dataset is preserved without modification.
Data cleaning is performed separately using Python and Pandas.
